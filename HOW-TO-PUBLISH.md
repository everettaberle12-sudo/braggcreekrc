# Putting the game online with GitHub Pages

Link: **https://everettaberle12-sudo.github.io/braggcreekrc/**

1. On github.com open **everettaberle12-sudo/braggcreekrc (renamed from Claude-Project)** → **Settings**.
2. **General** → scroll to the bottom (**Danger Zone**) → **Change visibility** → **Make public** and confirm.
3. **Pages** (left menu) → **Build and deployment** → Source: **Deploy from a branch**.
4. Branch: **claude/bragg-creek-rc-game-l7ejv1**, folder: **/docs** → **Save**.
5. Wait 1–2 minutes, then open the link above.

Updates: when Claude saves new changes to that branch, the site updates by itself in a minute or two.
